# 01 - Django Todo Application ✅

A simple and beautiful Todo app built with Django.

### Features
- User Signup & Login
- Add, Edit, Delete Todos
- Mark as Completed
- Secure Authentication

### Tech Stack
- Django, Python
- HTML, CSS
- SQLite

### How to Run
```bash
pip install django
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```
